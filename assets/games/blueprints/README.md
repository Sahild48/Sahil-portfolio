# Blueprints Game Assets

Drop your Blueprints project screenshots and media here.

### Quick Start:
1. Drop your images here (e.g. `thumb.jpg`, `mechanic-1.jpg`, `mechanic-2.jpg`, etc.).
2. Add or update one line in `assets/js/gallery-data.js`:
   ```js
   thumb: 'assets/games/blueprints/thumb.jpg'
   ```
3. You should never need to touch the layout code!
