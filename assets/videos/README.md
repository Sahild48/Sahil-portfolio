# Gameplay & Album Videos

Drop your local video captures (.mp4, .webm) here.

### Quick Start:
1. Drop your `.mp4` file here (e.g. `cpp-combat.mp4`, `blueprints-locomotion.mp4`, `event-cinematic.mp4`).
2. Add one line to `assets/js/gallery-data.js` under `PROJECT_VIDEOS` or `PHOTO_ALBUM.videos`:
   ```js
   src: 'assets/videos/cpp-combat.mp4'
   ```
   *(Or paste a YouTube embed link like `src: 'https://www.youtube.com/embed/...'`)*
3. You should never need to touch the layout code!
